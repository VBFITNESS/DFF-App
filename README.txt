DFF Personal v7
This is a mobile-first Progressive Web App build.
It stores DFF data locally in the browser and supports JSON backup/import.
For Android installation as an app, host these files on HTTPS and open the site in Chrome; then use Add to Home screen / Install app.
This build does NOT contain an AI API key. AI interpretation should be connected as a separate secure backend in a later step so no secret key is exposed inside the phone app.
