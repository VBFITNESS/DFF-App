DFF Personal v8
Daily Fixed Format personal PWA.

V8 implements the locked P1-P7 amendments:
- Week + Day + Date in Daily DFF Log
- Fixed cardio rates and fixed 40/50 km cycling models
- Custom Cardio and Custom Cycling with automatic Distance/Time/Speed completion
- Food servings to 2 decimals and Calories/Protein/Carbs/Fat/Fiber
- Supplement checklist with three customizable Other slots
- Full Today's Result table
- Weekly DFF Log D1-D7 + TOTAL + AVG; supplement values are displayed but not numerically averaged
- Activity Aggregation retained
- Pro-Takeaway with selectable goal and Simple English output
- Local JSON export/import backup

Base Burn is locked at 1,800 kcal/day.
